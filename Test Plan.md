# Test Plan

## Project
Sample Web Application

## Objective
To verify that all functional and non-functional requirements of the application are working as expected.

## Scope
### In Scope
- Login Module
- Registration Module
- Forgot Password
- Search Functionality
- User Profile

### Out of Scope
- Third-party payment gateway
- Performance Testing
- Security Testing

## Test Strategy
- Functional Testing
- Smoke Testing
- Regression Testing
- UI Testing
- Boundary Value Analysis
- Equivalence Partitioning

## Test Environment
- OS: Windows 11
- Browser: Chrome, Edge, Firefox
- Database: MySQL

## Entry Criteria
- Requirements approved
- Test environment ready
- Build deployed

## Exit Criteria
- All critical defects closed
- 95% test cases passed
- Test Summary Report completed

## Deliverables
- Test Cases
- Test Scenarios
- Bug Reports
- RTM
- Test Summary Report
